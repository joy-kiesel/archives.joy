# archives.joy

Portfolio site of Joyce Kiesel, brand and editorial designer.

Static site, no build step:

- `index.html` — page markup
- `style.css` — styles
- `main.js` — interactions (work strip, index, stickers, animations, cursor)
- `img/`, `vid/`, `svg/` — media

Deploy on Vercel as a static project (Framework preset: Other, no build command, output directory `.`).
